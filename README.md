# adportfolio

This repository is dedicated to showing off html5 ads that ive built.

## How to Download, Setup, and Run the Project Locally

### Step 1: Download the repository
- Go to the project's repository page on GitHub.
- Click the green **Code** button.
- Select **Download ZIP**.
- Extract the downloaded zip folder to an easily accessible location on your computer (like your Desktop).

### Step 2: Open in VS Code
- Open Visual Studio Code.
- Go to the top menu and click **File** > **Open Folder...**.
- Select and open the folder of the project you just extracted.

### Step 3: Install the Live Server extension
- On the left sidebar of VS Code, click on the **Extensions** icon (or press `Ctrl+Shift+X` on Windows/Linux or `Cmd+Shift+X` on Mac).
- Type `Live Server` into the search bar.
- Find the extension created by *Ritwick Dey* and click **Install**.

### Step 4: Run the project and view the ads
- Open the main file of the project (usually named `index.html`) in the VS Code editor.
- Look at the bottom right corner of the VS Code status bar and click the **Go Live** button.
- Your default browser will automatically open displaying the project, allowing you to browse and view the ads.
